Wii Format: A Simplistic Tool to Format Drives Above 32GB to FAT32.

How to use:
Download WiiFormat.exe from the Releases tab.
Run as Admin.
Pick the drive of your choice, and leave "Cluster Size" set as "Default" and click "Format to FAT32".
Type the letter of your drive and click "Format Drive".
WARNING!!! ⚠️ Selecting to format any drive will get rid of all data, so back up any important data before formatting.
Features:
Marks the partition as FAT32 LBA so the Wii recognizes it.
Set your own volume label.
Leave "Quick Format" off if you wish to have a full format.
